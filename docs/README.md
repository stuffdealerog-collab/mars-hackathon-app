Product decisions in short: the primary user is a small-business owner without a marketer; the first screen is a task box ("Topshiriq bering") plus an approval inbox, with the node canvas as the second layer; the killer feature is "Bir havola — butun marketing bo‘limi" (one channel link → the whole department in about a minute); nothing is published until the owner taps Publish, and promotions, prices, videos and first posts are flagged for approval by default (autopilot for routine posts is a beta setting); the price hypothesis is 7 days free, then 149 000 UZS per month.
