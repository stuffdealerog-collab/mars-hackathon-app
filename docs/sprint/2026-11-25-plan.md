## Что сломано или врёт (главное)

1. При любой ошибке Studio тихо подменяет канал владельца образцом «Nafis kiyim» (`api.ts:60-69`, `store.ts`).
2. Посты пишутся из сырого текста задачи, а не из недельного плана (`store.ts:249`).
3. Публикация из веба — тупик: бот не обрабатывает `start=publish_<id>`; веб-бренды без владельца → 403.
4. Одобрение живёт только в памяти браузера; `posts.status='approved'` никогда не пишется.
5. Находки аудита на жаргоне разработчика (`hiddenPrice 0 · priceShareInSale 12.2% [S.ctaRate, R.DEAD_ENDS]`).
6. Фейковые данные как настоящие: «BUGUN…» в «Jamoa», «ULANGAN», LED с `@KANALINGIZ`, «Har bir raqam kanal ma'lumotidan».
7. Картинок нет вообще; публикация — только текст (`sendMessage`).
8. Studio: 8 вкладок, 7 из них в старом тёмном «AI OS» (GlowCard, орбы, ИИ-портреты, неон). Лендинг дважды показывает панель из 10 ламп.
9. Лендинг только на узбекском, Studio без i18n.

## Направление дизайна (исправлено владельцем 24.11 ~19:40)

Основа — «ламповый мир» из PR #4: тёмная сцена, отдел как панель ламп, которые горят только пока сотрудник работает или держит результат; момент Spektr (поле сжимается в точку света → лучи → лампы) как вау-эффект; янтарное LED-табло только для измеренных чисел; лайм только для действий владельца; шрифт Onest. Владелец: «прошлый был красивый, его надо чуть упростить и сделать понятным; обёртка важна; нужен вау-эффект». Светлый «бумажный» вариант отклонён как сухой.

Упрощаем: одна панель ламп на лендинге вместо двух; на каждом экране понятно, что происходит и что делать дальше; у горящей лампы короткая честная подпись («60 post o‘qildi»); роли, которые завтра не работают, остаются тёмными с «tez orada». Убираем то, что было похоже на Higgsfield: старые тёмные «AI OS»-экраны (GlowCard с mesh-градиентами, глянцевые орбы, ИИ-портреты, точечная сетка, неоновые плашки) — их содержимое переносим в ламповую систему. Анимации — на максимум по качеству, плавно в Telegram на среднем Android. Простой режим по умолчанию, «Professional rejim» отдельно. Весь продукт на uz / ru / en.

### Контракт (уже в `src/lib/uslub/contract.ts`)

- `BrandProfile.mode`: `"channel"` (есть канал с историей) или `"fresh"` (пустой канал, бренд из описания).
- `BrandProfile.visual?: VisualStyle` — визуальный стиль: ссылки-референсы (фото канала и владельца), палитра, свет, композиция, предметы, настроение, чего избегать.
- `PostDraft.image?: PostImage` — картинка поста: статус, url, промпт, сколько референсов использовано.
- `PostDraft.slot?: PlanSlot` — из какого пункта плана написан пост (день, время, цель, хук, CTA).

### Схема БД (уже в `db/schema.sql`, только добавления)

`brands.mode`, `brands.visual`, `posts.image`, `posts.slot`, `posts.approved_at`, таблица `media_jobs` (раньше создавалась на лету).
