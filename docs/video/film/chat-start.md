# Как начать генерацию

Всё готово к старту: твои фото и 26 3D-черновиков уже лежат в твоём Higgsfield, загружены из Claude Code бесплатно. Кредитов по-прежнему 2, их не трогаем.

**Безлимит до 27.11, 02:27 по Ташкенту.** Поэтому сегодня ночью — только P1, завтра — P2 и P3.

## 0. Где

Только **claude.ai** (или Cowork): новый чат, коннектор Higgsfield включён на том же аккаунте. Не Claude Code — оттуда безлимит не работает.

## Сообщение 1 — правила

Скопируй из [`chat-prompts.md`](chat-prompts.md), раздел «Шаг 0», весь блок кода: от «Ты — мой ассистент…» до «Ответь «Готов»…». Чат ответит «Готов» и покажет, что покрывает безлимит. Если там `unlim.available: false` — ничего не генерируй и напиши мне.

## Дальше — по `chat-prompts.md`, по порядку

**Хочешь, чтобы чат работал сам, пока ты спишь,** — вместо пунктов ниже вставь сообщение 3 из [`chat-night.md`](chat-night.md).

1. **Шаг 2** — листы корабля и скафандра, 4 картинки. Выбери по одной: от них зависит весь фильм.
2. **Шаг 3** — сначала правило, потом список **3.1 (P1)**: ключевые кадры начала, твой выбор, потом концы.
3. **Шаг 4** — правило, потом **4.1 (P1)**: видео по 3 дубля на кадр. Чат сам проверит дубли и даст таблицу; ты выбираешь.
4. Если остаётся время — **3.2 → 4.2 (P2)**, потом **3.3 → 4.3 (P3)**.
5. **Шаг 6**, голоса PromptX, — в любой момент, пока ждёшь видео.
6. **Шаг 8** (замена фона, наезд на глаза 1.4) — после того как снимешь подъезд 1.2 и 1.3.
7. **В конце каждого сеанса** напиши чату «СПИСОК» и сохрани ответ (JSON) в `docs/video/film/footage/selected-<дата>.json`. Ссылки Higgsfield живут 7 дней; по этому файлу Claude Code скачает всё для монтажа.

Если дубль не нравится — меняй одну вещь за раз (раздел «Как выбирать дубли» в `chat-prompts.md`). Если чат пишет, что генерация стоит кредитов, — стоп, ничего не подтверждай.
